# ISC2 Certified in Cybersecurity
## Domain 1: Security Principles

---

# CIA Triad

The CIA Triad represents the three core principles of cybersecurity:
- Confidentiality
- Integrity
- Availability

---

# 1. Confidentiality

Confidentiality means protecting information from unauthorized disclosure while allowing authorized access.

## Key Concepts
- access control
- privacy
- protection of sensitive information

## Sensitive Information Types
### Personally Identifiable Information (PII)
Information that can identify an individual.

Examples:
- names
- ID numbers
- addresses
- phone numbers

### Protected Health Information (PHI)
Sensitive medical and healthcare-related information.

Examples:
- medical records
- prescriptions
- treatment history

## Sensitivity
Sensitivity refers to the importance assigned to information by its owner.

---

# 2. Integrity

Integrity ensures information remains:
- accurate
- complete
- trustworthy
- unaltered

## Types of Integrity

### Data Integrity
Ensures data has not been modified in an unauthorized manner.

### System Integrity
Ensures systems function correctly and remain uncorrupted.

---

# Baselining

Baselining is:
- a documented
- approved
- tested snapshot

of a secure system configuration at a specific point in time.

Purpose:
- establish trusted system state
- detect unauthorized changes

---

# 3. Availability

Availability ensures systems and data remain accessible when needed.

## Important Concepts
- uptime
- reliability
- accessibility

## Critical Assets
Critical assets are systems or processes essential to organizational operations and survival.

---

# Authentication

Authentication verifies the identity of a user or system requesting access.

## Authentication Methods

### Something You Know
Examples:
- passwords
- passphrases

### Something You Have
Examples:
- smart cards
- security tokens

### Something You Are
Examples:
- fingerprints
- facial recognition
- biometrics

---

# Authentication Types

## Single-Factor Authentication (SFA)
Uses one authentication method only.

## Multi-Factor Authentication (MFA)
Uses two or more authentication methods for stronger security.
