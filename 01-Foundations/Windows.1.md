- View CPU, RAM, Disk, and Network usage
- End unresponsive tasks

## Windows File System

### NTFS (New Technology File System)
**Main Windows file system with the following features:**
- File and folder permissions
- Encryption support (EFS)
- Compression
- Journaling
- Better security and reliability

### Permissions
- Learned how to change permissions on files and folders
- Understood basic Access Control concepts

---

## Important Windows Directories

- **System32** — Contains critical Windows system files and utilities
- **%windir%** — Environment variable pointing to the Windows installation directory

---

## User Accounts

- **Administrator Account** — Full system control (install software, change settings)
- **Standard User Account** — Limited permissions for safer daily use

**Key Difference:**
- Administrator has elevated privileges
- Standard User has restricted access for better security

---

## UAC (User Account Control)
- Prevents unauthorized system changes
- Prompts user before performing elevated actions

---

## Settings vs Control Panel
- **Settings** — Modern Windows configuration interface
- **Control Panel** — Traditional management interface
