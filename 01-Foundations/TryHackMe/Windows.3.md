- security updates

- system improvements

- Patch Tuesday

# Windows Security

Windows Security is used to manage tools that protect:
- devices
- files
- user data

## Main Sections
- Virus & Threat Protection
- Firewall & Network Protection
- App & Browser Control
- Device Security

## Status Indicators
- Green = Protected
- Yellow = Security recommendations available
- Red = Immediate attention required

## Main Areas
- Current Threats

# Scan Options

## Quick Scan
Checks common locations where malware is usually found.

## Full Scan
Scans:
- all files
- running programs
- hidden files
- boot sectors

## Custom Scan
Allows scanning of specific files or folders.

## Microsoft Defender Offline Scan
Scans for malware before user login.

---

# Threat History

## Last Scan
Shows recent malware scans.

## Quarantined Threats
Threats isolated from the system.

## Allowed Threats
Threats manually permitted to run.

---

# Virus Protection Settings

## Real-Time Protection
Detects and blocks malware in real time.

## Cloud-Delivered Protection
Uses Microsoft cloud intelligence for faster protection updates.

## Automatic Sample Submission
Sends suspicious files to Microsoft for analysis.

## Controlled Folder Access
Protects files and folders from unauthorized modifications.

## Exclusions
Prevents selected files or folders from being scanned.

---

# Firewall & Network Protection

Firewall controls traffic entering and leaving the system through network ports.

## Firewall Profiles

### Domain Profile
Used when connected to organizational domain networks.

### Private Profile
Used for trusted home or private networks.

### Public Profile
Default profile used on public networks.

# Core Isolation

Protects critical system processes from malware attacks.

## Memory Integrity
Prevents malicious code injection into secure processes.

# Trusted Platform Module (TPM)

TPM is hardware-based security technology used for:
- cryptographic operations
- device security
- encryption support

## TPM Chip
A secure cryptoprocessor designed to handle encryption-related functions.

---

# BitLocker

BitLocker is a full-disk encryption feature used to protect data from unauthorized access.

## Best Protection
Systems with TPM provide stronger BitLocker protection.

---

# Volume Shadow Copy Service (VSS)

VSS allows backup snapshots of files or volumes while they are actively in use.

Purpose:
- backups
- recovery
- restore points
