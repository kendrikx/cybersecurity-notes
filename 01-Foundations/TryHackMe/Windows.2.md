# Windows Fundamentals 2

## System Configuration (MSConfig)

### Purpose
MSConfig is an advanced troubleshooting utility used to diagnose startup and boot issues.

### Main Tabs

#### General
Controls which drivers and services load during startup.

#### Boot
Configure boot options and startup behavior.

#### Services
Manage Windows and third-party services.

#### Startup
Manage startup applications.

#### Tools
Provides access to additional Windows troubleshooting and management tools.

---

# Advanced System Settings

Used to configure:
- Performance settings
- Startup and recovery options
- Environment settings

### Important Tabs
- Computer Name
- Hardware
- Advanced
- System Protection

### Virtual Memory / Pagefile
Windows uses a pagefile on disk as additional virtual memory when physical RAM becomes full.

---

# User Account Control (UAC)

### Purpose
Helps prevent unauthorized system changes.

### Features
- Security notification prompts
- Adjustable security levels using slider settings
- Can also be configured through MSConfig

---

# Computer Management (compmgmt.msc)

Central management console divided into three major sections.

## 1. System Tools

### Task Scheduler
Used to:
- automate tasks
- run scripts/programs at scheduled times

### Event Viewer
Used to:
- view logs
- monitor system events and errors

## 2. Storage
Includes Disk Management utilities.

## 3. Services
Manage Windows services running on the system.
