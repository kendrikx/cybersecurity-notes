# Windows Command Line

## Overview
The Windows Command Line (cmd.exe) is a text-based interface used to interact with the operating system.

## Benefits
- Speed and efficiency
- Lower resource usage
- Automation
- Remote administration

## System Information Commands
### set
Displays environment variables and command paths.

### ver
Displays Windows version information.

### systeminfo
Displays detailed operating system information.

### cls
Clears the command prompt screen.

## Network Configuration
### ipconfig
Displays network configuration information.

### ipconfig /all
Displays detailed network configuration information.

## Network Troubleshooting
### ping
Tests connectivity to another host.

### tracert
Shows the route packets take to a destination.

## Network Analysis
### nslookup
Resolves domain names to IP addresses.

### netstat
Displays active connections and listening ports.

#### Common Switches
- -a : Show all connections and listening ports
- -b : Show associated executable
- -o : Show PID
- -n : Show numerical addresses

## File and Directory Management
### cd
Change directory.

### dir
List directory contents.

### dir /a
Display hidden and system files.

### dir /s
Display files recursively.

### tree
Display directory structure.

### mkdir
Create directory.

### rmdir
Remove directory.

## File Operations
### type
Display text file contents.

### more
Display file contents one page at a time.

### copy
Copy files.

### move
Move files.

### del
Delete files.

## Process Management
### tasklist
Display running processes.

### taskkill
Terminate running processes.
